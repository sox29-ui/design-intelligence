# Ledgerline · Reconciliation overview

- **Queue first.** KPIs, then the exceptions table; trend and activity sit in a sticky rail. Opening a row turns the rail into the detail panel; table and KPIs stay visible (modal sheet below 1360px).
- **Explicit urgency:** open 3+ days (SLA) or €5,000+. Icon plus text, an "Urgent only" filter and a KPI shortcut; the default sort is oldest first.
- **Never colour alone:** status chips pair icon shape with a label; KPI deltas say "better/worse than…".
- **Comparable numbers:** tabular figures, right-aligned amounts, a separate currency column, amount sort by EUR equivalent.
- **Chart:** small multiples on separate scales, because unmatched is ~3% of volume and a stacked chart would hide it. Arrow keys explore it, and a data table is available.
- **Filter scope:** date, provider and entity drive the whole page; status lives on the table it scopes.
- **Keyboard:** the table is one tab stop. Arrows move, Enter opens (details follow the cursor), Esc returns focus; "/" searches.
- **Context:** the missing Klarna report notice says which exceptions to leave for now.
- **Phone:** read-only KPIs and the urgent list.
- Seeded sample data, generated in-browser relative to today.
