### Mobile navigation as a full sheet or in-flow panel with real state
<!-- rule:components.mobile-menu-sheet -->
`components.mobile-menu-sheet` · principle · confidence **medium** · evidence: 5 independent ref(s) · provisional

**On mobile, open navigation as a full-height sheet or an in-flow panel; expose aria-expanded, close on Escape, and keep the primary action reachable inside it.**

- **WHEN:** device ∈ {mobile-first, responsive-general}
- **CONSIDER:** drill-down chevrons for nested sections; primary CTA pinned at the bottom of the sheet; model/category tiles inside the sheet for commerce
- **VERIFY:** aria-expanded false → true; Escape closes and returns focus; body scroll locked only while a modal sheet is open; RTL: chevrons point left
- **TRADE-OFFS:** full sheets hide page context
- **WHY (inferred):** Five references implement measured aria-expanded state and Escape-to-close; the strongest also place the conversion action inside the sheet.
- *Evidence:* supported by ref-009 (Stripe), ref-007 (GOV.UK), ref-010 (Tabby), ref-003 (Scout Motors), ref-002 (Shopify Editions — The Renaissance Edition (Winter '26)) · counterexamples: ref-001 (Lando Norris) — toggle exposed no state change in capture (inconclusive) · validation: val-002: inconsistent. Details: `npm run why -- components.mobile-menu-sheet`.

### Keep the one conversion action persistent
<!-- rule:components.persistent-primary-action -->
`components.persistent-primary-action` · principle · confidence **medium** · evidence: 3 independent ref(s) · provisional

**On conversion pages, keep the single primary action (reserve, start, download, add to cart) visible in the header at every width and inside the mobile menu, so storytelling never strands a ready visitor.**

- **WHEN:** page_goal ∈ {conversion}
- **CONSIDER:** header CTA at 390 and 1440; CTA repeated at the end of each story section; pricing/terms disclosure near the first CTA
- **VERIFY:** CTA visible in the first viewport at 390; CTA reachable within the first 5 tab stops
- **AVOID WHEN:** task tools where a persistent sales CTA distracts from work
- **TRADE-OFFS:** repetition can feel pushy if overused
- **WHY (inferred):** The automotive launch keeps "reserve" in the header and the mobile menu; the payments site pins both CTAs in its mobile menu and header; the fintech app keeps a single download CTA in each section.
- *Evidence:* supported by ref-003 (Scout Motors), ref-009 (Stripe), ref-010 (Tabby). Details: `npm run why -- components.persistent-primary-action`.

`components.trust-next-to-the-ask` · principle · confidence **medium** · evidence: 4 independent ref(s) · provisional

- **WHEN:** page_goal ∈ {conversion}

- *Evidence:* supported by ref-010 (Tabby), ref-009 (Stripe), ref-012 (Ounass), ref-003 (Scout Motors). Details: `npm run why -- components.trust-next-to-the-ask`.

### Data displays: label directly, offer a table, show values
<!-- rule:components.data-display-direct -->
`components.data-display-direct` · principle · confidence **low** · evidence: 2 independent ref(s) + 1 standard(s) · provisional

**In data views label series directly at the data, offer an equivalent table, show current values beside selections, and give KPIs large, light numerals with short captions.**

- **WHEN:** page_goal ∈ {data-interaction, information-consumption}
- **CONSIDER:** end-of-line labels in series colour; table toggle; values with proportional bars in selection lists; tabular figures for numbers
- **VERIFY:** chart has a text alternative or table; series distinguishable without colour; numbers right-aligned in tables
- **TRADE-OFFS:** direct labels need right-margin space
- **WHY (inferred):** The data publication labels lines directly, offers table/map/line/bar views and shows values beside each selectable region; the payments site presents KPIs as large light numerals with two-line captions.
- *Evidence:* supported by ref-008 (Our World in Data), ref-009 (Stripe) · standards: wcag22. Details: `npm run why -- components.data-display-direct`.
